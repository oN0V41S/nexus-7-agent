Use a skill `mem-search` para consultar a memória do harness Nexus.

$ARGUMENTS

Siga o progressive disclosure pattern:
1. SEARCH: nexus-memory action=search para índice compacto
2. LOAD: nexus-memory action=load para detalhes completos
3. HANDOFF: nexus-handoff action=apply para retomar contexto
