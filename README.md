# Nexus 7 Agent

**Nexus 7 Agent** é um ecossistema de Agentes de IA com suporte a MCP (Model Context Protocol), projetado para orquestração de tarefas, automação de código e gestão de conhecimento.

## Stack

- **Runtime:** Node.js
- **MCP Servers:** Notion, Playwright
- **Code Intelligence:** opencode

## Configuração

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/nexus-7-agent.git
   cd nexus-7-agent
   ```

2. Configure as variáveis de ambiente:
   ```bash
   cp .env.examle .env.local
   ```

3. Abra o projeto com opencode:
   ```bash
   opencode
   ```

## MCP Tools

- **Notion** — gerenciamento de documentação e páginas
- **Playwright** — automação de navegador e testes E2E
