# Nexus 7 Agent — Hermes Context

## Visão Geral

Ecossistema de Agentes de IA 100% local para orquestração de tarefas, automação de código e gestão de conhecimento. Construído sobre OpenCode com pipeline harness de 6 estágios e integração completa com ferramentas MCP.

## Stack

| Camada | Tecnologia |
|--------|-----------|
| **Infraestrutura** | Docker, Ollama (LLM local), n8n (automação), Open WebUI |
| **Orquestrador** | OpenCode + oh-my-opencode-slim (multi-agente com roteamento de modelos) |
| **LLM Providers** | Ollama (local), OpenAI (GPT), Google (Gemini) |
| **MCP Servers** | Nexus Memory Server, Google Workspace MCP, Notion MCP, Playwright MCP, Chrome DevTools MCP, Codebase Memory MCP, TestSprite MCP |
| **Pipeline** | Harness de 6 estágios: SPEC → PLAN → ANALYZE → BUILD → REVIEW → DOCUMENT |
| **Custom Tools** | nexus-log, nexus-memory, nexus-handoff, spec-validator |
| **Plugin System** | Nexus Plugin (observabilidade), Superpowers (500+ skills) |
| **Dashboard** | Nexus Dashboard Web (Express) |
| **Storage** | SQLite com FTS5 (memória persistente) |
| **Hermes Profile** | `~/.hermes/profiles/nexus-7/` |

## Pipeline de 6 Estágios (Harness)

O pipeline é orquestrado pelo `@orchestrator` e delega automaticamente a sub-agents especializados por estágio:

| Estágio | Descrição | Agente Responsável |
|---------|-----------|-------------------|
| **SPEC** | Especificação formal do requisito (Spec Driven Development) | `@spec-reviewer` |
| **PLAN** | Planejamento de implementação e arquitetura | `@oracle` |
| **ANALYZE** | Análise de código, dependências e impacto | `@explorer`, `@cbm-agent` |
| **BUILD** | Implementação do código | `@fixer`, `@designer` |
| **REVIEW** | Revisão de qualidade, segurança e testes | `@security-secret-auditor`, `@quality-assurance-analyst` |
| **DOCUMENT** | Documentação técnica e atualização de specs | `@docs-architect` |

**Entrada:** `/super-pipeline` — Pipeline completo com delegação automática
**Spec Driven Development (SDD):** Gere specs com `/spec-gen`, revise com `/spec-review`

## Ferramentas Customizadas (Custom Tools)

| Tool | Descrição |
|------|-----------|
| `nexus-log` | Log estruturado para `.opencode/logs/`. Níveis: info, warn, error, debug, trace |
| `nexus-memory` | Persistência de contexto entre sessões (SQLite + FTS5). Ações: save, load, list, delete, search. Dual-mode: custom tool + MCP server |
| `nexus-handoff` | Handoff entre agentes/sessões em `.opencode/memory/handoffs/`. Ações: create, apply, list |
| `spec-validator` | Valida documentos .spec.md contra o JSON schema Nexus |

## Convenções

- **Linguagem:** Português para comunicação com o usuário
- **Commits:** Descritivos e atômicos, usando `/commit-&-docs`
- **Pipeline:** Sempre iniciar com `/super-pipeline` para tarefas complexas
- **Sub-agents:** Usar `task("descrição", "@agent-name")` para delegação
- **Logs:** Usar `nexus-log` para registrar eventos importantes
- **Memória:** Usar `nexus-memory` para salvar/recuperar contexto entre sessões
- **Handoff:** Usar `nexus-handoff` antes de pausar tarefas longas
- **Backup Protocol:** Antes de sobrescrever arquivos existentes, avisar o usuário. Usar `git diff` para mostrar mudanças em arquivos versionados. Criar pasta `log/ALTERAÇÃO/` para mudanças em arquivos não versionados.
- **Specs:** Seguir padrão SDD (Spec Driven Development) — gerar `.spec.md` em `docs/spec/` antes de implementar

## Hermes Profile

O projeto Nexus 7 é integrado ao Hermes Agent via profile dedicado em `~/.hermes/profiles/nexus-7/`:
- **Skills:** Wrappers dos comandos/agents do `.opencode/` + skills originais
- **Plugins:** nexus-log e nexus-memory adaptados
- **Scripts:** Adaptações das custom tools (shell/python)
- **Config:** `.hermes.md` (este arquivo) para contexto do projeto
